# Launchly — UI/UX Design Assignment

## Overview

Launchly is a fictional email marketing platform designed to help
small businesses create and send professional email campaigns.

This project focuses on creating a simple, intuitive campaign creation
flow along with a marketing poster for Launchly.

## Objective

The objective was to demonstrate:

- UI/UX design
- User flow and interaction design
- Visual design
- Figma skills
- Marketing design
- AI-assisted design

## User Flow

Create Campaign
→ Create Email
→ Select Audience
→ Schedule / Send
→ Confirmation

## Final Screens

The final product flow includes:

1. Create Campaign
2. Create Email
3. Select Audience
4. Schedule / Send
5. Confirmation

## Marketing Poster

A social-media marketing poster was created for Launchly around the theme:

**“Send Better Emails. Reach More People.”**

The final poster was created and refined using Mailtr and exported as a marketing image.

## Design System

The Figma design includes:

- Color palette
- Typography system
- Spacing system
- Reusable components
- Interaction states
- Auto Layout

## Exploration

The exploration phase includes:

- User flow
- Low-fidelity wireframes
- UI exploration
- Component exploration
- Marketing poster exploration

## AI Usage

AI was used as a supporting tool for:

- UX and visual ideation
- Marketing copy exploration
- Supporting visual generation

AI-generated visuals were refined and integrated into the final marketing poster.

## Tools

- Figma
- Mailtr
- ChatGPT
- Gemini
